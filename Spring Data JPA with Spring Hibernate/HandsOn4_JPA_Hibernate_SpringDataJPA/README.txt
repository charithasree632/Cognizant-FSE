Difference between JPA, Hibernate and Spring Data JPA

1. JPA
- Java Persistence API specification.
- Defines annotations like @Entity, @Table, @Id.
- No implementation.

2. Hibernate
- ORM framework implementing JPA.
- Handles object-relational mapping.

3. Spring Data JPA
- Built on top of JPA.
- Uses Hibernate internally.
- Reduces boilerplate using JpaRepository.
- Automatic transaction management.
